# Competitive gaming fMRI hyperscanning analysis code

This repository contains analysis code for a dual-scanner fMRI hyperscanning
study of real-time competitive gaming.

## Code packages

- `whole_brain_permutation`: voxel-wise inter-brain correlation analysis,
  pseudo-dyad permutation testing, and AFNI cluster-extent correction for the
  Continuous Gaming task.
- `social_interaction_analysis`: construction of visual, motor, and
  minimap-derived social-interaction measures; ROI brain-behavior models;
  30-s sensitivity analyses; and temporal-dependence permutation tests.

Each package has its own README with inputs, dependencies, execution order,
and output descriptions. Data are not included in this repository.

## Study

The code accompanies a manuscript examining inter-brain synchrony during
naturalistic dyadic competition using simultaneous fMRI acquisition.
